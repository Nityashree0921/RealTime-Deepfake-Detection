3. LABEL CONVENTION & MAPPING AUDIT
--------------------------------------------------------------------------------
Keras Directory Inferred Alphabetical Ordering:
- Class 0: "fake"
- Class 1: "real"
Model Output: Sigmoid activation neuron in [0, 1]
Mathematical Interpretation:
  y_pred = P(REAL | x)
  P(FAKE | x) = 1.0 - y_pred

Audit of Past Bugs in V5 / Testing scripts:
- In `test_webcam_real.py`: Images loaded with label 0=REAL, 1=FAKE, causing confusion between P(REAL) and P(FAKE).
- In `deepfake_detector.py`: Normalized face by `/ 255.0` while model already contained internal `Rescaling(1/127.5, offset=-1)`, causing duplicate rescaling.
- In `realtime_detector.py`: Treated `prediction >= threshold` as FAKE instead of REAL, inverting the model's confidence logic.


4. MODEL ARCHITECTURE & PREPROCESSING AUDIT
--------------------------------------------------------------------------------
Model Backbone:
- Input Shape: (224, 224, 3)
- Built-in Data Augmentation: Horizontal Flip, Rotation, Zoom, Contrast
- Built-in Preprocessing: `layers.Rescaling(1.0 / 127.5, offset=-1)` -> converts [0, 255] to [-1, 1]
- Feature Extractor: `MobileNetV2(include_top=False, weights='imagenet')`
- Pooling: `GlobalAveragePooling2D()`
- Dense Head: Dropout(0.40) -> Dense(128, activation='relu') -> Dropout(0.30) -> Dense(1, activation='sigmoid')

V5 Bottleneck Analysis:
- V5 froze the entire MobileNetV2 base permanently without fine-tuning higher-level feature extractors.
- On the small dataset of 448 frames, generic ImageNet features alone struggled to separate subtle deepfake warping artifacts without selective unfreezing.
- Mean prediction of V5 on test set hovered at ~0.498 (FAKE) and ~0.470 (REAL), yielding near-chance ROC-AUC (~0.47-0.58).


5. REAL-TIME INFERENCE PIPELINE AUDIT
--------------------------------------------------------------------------------
Detection Chain:
Webcam Frame -> OpenCV SSD Caffe Face Detector (`face_detector.py`) -> Crop Largest Face -> BGR to RGB -> Resize to (224, 224) -> Float32 Array -> Model Internal Rescaling -> MobileNetV2 -> Dense Sigmoid -> Temporal Smoothing (Deque of 15 frames) -> Result & Probability Visualization.

Bottlenecks Identified & Solutions:
1. Realtime script (`realtime_detector.py`) previously pointed to `deepfake_face_model_v2.keras` and inverted the binary label meaning.
2. We will update `realtime_detector.py` and `deepfake_detector.py` to point to `deepfake_face_model_v6.keras`, with correct probability handling ($P(\text{REAL}) = \text{output}$) and optimal validation-selected threshold.
